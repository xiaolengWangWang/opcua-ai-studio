# OPC UA AI Studio 操作手册

本手册随程序离线提供，点击菜单“帮助 › 操作手册”打开。程序默认只读，写入须明确允许并逐次确认。

## 快速开始

1. 点击“搜索服务器”查找本机所在网段的 OPC UA 服务器，点“连接”直接连接；或在“地址”填写 `192.168.1.10`、“端口”填写 `4840`。
2. 需要账号、证书或特定安全策略时，点击端口右侧的设置按钮（齿轮）打开“连接设置”。
3. 点击“连接”。连接成功后右上角显示“已连接”和服务器产品名称。
4. 在“节点浏览”找到设备或文件夹，点击“读取此节点下全部变量”；或在“点位与读写”中单点验证、读取节点清单、全量读取（父节点可填 `i=85` 或 `ns=2`）。
5. 在结果区搜索、筛选、点击表头排序，勾选“自动刷新”持续更新数值，用“视图”切换表格、树状、卡片或趋势，用“导出”导出 CSV 或 viSCADA 属性表。
6. 需要写入时，点击可写点位的“值”（或卡片上的写入按钮）打开写入对话框，勾选“允许写入”后写入并读回。

没有现场服务器时，点击菜单“连接 › 启动本机演示”启动回环演示服务器并自动连接，可练习全部功能。

## 界面总览

- 菜单栏：不常用的操作按类别收在菜单中，界面只留常用按钮，为数据区留出空间。
  - 文件：新建窗口、导入属性表验证、导出 CSV、导出 viSCADA 属性表、复制结果、打开记录目录、历史日志、退出。
  - 连接：连接、断开、搜索服务器、发现端点、连接设置、保存 / 删除连接配置、连接记录、断线自动重连、连接后自动全量读取、服务器信息、连接数测试、启动 / 停止本机演示。
  - 读取：单点验证、写入选中点位、读取节点清单、开始 / 停止轮询、全量读取、停止读取、自动刷新结果。
  - 视图：表格、树状、卡片、趋势视图，显示左侧操作栏，展开 / 折叠全部文件夹，切换页签。
  - 帮助：操作手册、质量与统计说明、检查更新、关于（含通讯记录目录）。
- 连接栏：已保存的连接、连接记录（时钟按钮）、地址（下拉为最近连接）、端口、连接设置（齿轮）、搜索服务器、连接（连接后变为断开）；右侧为基准点位、连接状态，发现新版本时出现“新版本”按钮。各部分宽度固定，读写时地址框不会变窄。
- “点位与读写”页：左侧为可折叠的“单点验证与写入”“节点清单与轮询”“全量读取”“viSCADA 属性表”，默认只展开第一项；右侧为结果区。
- 结果区工具栏一行：折叠左栏按钮、搜索框、模糊 / 精确、筛选、视图（趋势视图时多一个时间范围）、自动刷新与间隔、写入、导出。下方一行为统计和读取状态，罕见的计数（UNCERTAIN、不存在、请求失败等）为零时不显示；统计前的“?”按钮说明各项计数的含义与作用。
- “节点浏览”页：父节点、搜索节点、勾选并读取。
- “通讯与日志”页：可筛选、搜索的请求记录表，选中一条查看全部目标和结果，下方为运行日志；“历史日志”“连接记录”从记录数据库读取以前的记录。
- “AI 诊断”页：预览证据后由用户确认发送。

窗口大小在退出时保存，下次按上次大小打开，并始终限制在屏幕可用区域内；屏幕较窄时左栏默认更窄。界面随 Windows 的缩放比例和浅色、深色设置调整。点击结果区左上角的折叠按钮（或菜单“视图 › 显示左侧操作栏”）收起左栏，让数据区占满窗口。

## 多开

可以同时打开多个窗口，分别连接不同的服务器：点击菜单“文件 › 新建窗口”，或再次双击程序。

- 每个窗口有自己的连接、结果、轮询和自动刷新，互不影响；窗口标题显示所连服务器（如“OPC UA AI Studio 0.7.0 · 192.168.1.10:4840”），便于在任务栏区分。
- 各窗口共用连接配置、最近连接、基准点位和通讯记录：同一天的记录写入同一记录文件，多个窗口同时写入不冲突；同时启动的窗口可能各建一个当天的文件，记录都会保留。
- 在一个窗口中保存的连接配置和设置，新打开的窗口即可使用。
- 一个窗口在程序内更新后，其他已打开的窗口仍运行旧版本，关闭后重新打开即为新版本；旧版本文件在不再使用后自动清理。

## 连接服务器

### 地址与端口

“地址”填写服务器的 IP 或主机名，“端口”填写端口（默认 `4840`，KEPServerEX 为 `49320`），程序组成 `opc.tcp://地址:端口` 连接。地址下拉列表保存最近成功连接的 10 个服务器，点选即同时填入地址和端口。在地址中粘贴完整的 `opc.tcp://…` 地址时，程序自动拆分为地址和端口，并保留其中的路径（如 `/OPCUA/SimulationServer`）。

### 搜索服务器

点击“搜索服务器”打开搜索窗口：

- “搜索范围”默认为“本机网段”：本机实际网卡（如 WLAN、以太网）的网段（如 `10.3.150.0/23`）。下拉可改选其他网卡的网段、“仅本机 127.0.0.1”或“指定 IP 或网段”。
- “主机 / 网段”始终可以修改：选择网段后可直接改成一台主机（如 `192.168.1.10`）、范围（如 `192.168.1.10-50`）或网段（如 `192.168.1.0/24`，最大 /20），逗号分隔；修改后搜索范围自动变为“指定 IP 或网段”，程序记住上次填写的内容，下次打开仍是它。
- 程序不搜索 VPN、代理隧道、虚拟机等虚拟网卡的网段（下拉中标为“虚拟网卡”，需要时可手动选择），也跳过 /31、/32 等主机路由。
- “端口”默认为常用 OPC UA 端口：4840、4841（标准）、4862（WinCC）、4890（WinCC Unified）、48010（Unified Automation 演示）、49320（KEPServerEX）、53530（Prosys）、62541（OPC Foundation 参考服务器、Ignition）。可增删，也可写范围如 `4840-4850`；点击“恢复默认端口”换回。

点击“开始搜索”，状态行先显示地址总数和最长耗时。搜索分两步：先对每台主机尝试第一个端口（默认 4840），再只对有回应的主机（端口开放，或在本机网段内应答了 ARP）尝试其余端口，不存在的主机只尝试一次，网段越空搜索越快。连接尝试按每秒约 800 次平稳进行；端口一开放就查询其端点，确认是 OPC UA 服务器即加入列表，不必等全部扫完；同时向找到的服务器查询在其发现服务登记的其他服务器。列表按 IP 地址排序，显示名称、地址、端点数、安全策略和认证方式。可随时“停止搜索”或关闭窗口，搜索立即结束。

本机网段内的主机从该网卡自身的地址连接：电脑上的代理软件（如 TUN 模式）接管默认路由时，连接不再经过代理，代理不会被成千上万的连接拖慢，也不会把每个端口都误报为开放。

点击服务器右侧的“连接”直接连接；点击“填入”（或点击该行）只填入地址和端口，并选用其无加密（None）端点的安全策略；服务器只提供加密端点时选用第一个，并打开“连接设置”。

搜不到服务器时，请确认服务器已启动、端口正确，且服务器和本机防火墙放行该端口。

### 连接设置

点击端口右侧的设置按钮（齿轮）或菜单“连接 › 连接设置”打开，顶部显示当前设置（如“None / None · 匿名”）。其中可设置安全策略（None、Basic256Sha256、Aes128_Sha256_RsaOaep、Aes256_Sha256_RsaPss）、安全模式、超时、用户名和密码，以及客户端证书、客户端私钥和可信服务器证书。加密策略必须提供三个证书文件；服务器证书与可信证书不一致时拒绝连接。

点击其中的“发现端点”列出服务器的全部端点（安全策略 / 模式 / 认证方式 / URL），点选一个即填入安全策略和模式，地址保持当前输入：服务器常报告本机无法解析的主机名。

“连接后自动全量读取”勾选后，每次连接成功即按“全量读取”中的父节点（如 `i=85` 或 `ns=2`）读取全部变量。

### 连接配置

常用的连接可保存为配置：填好地址、端口和连接设置后，点击菜单“连接 › 保存连接配置”，输入名称（默认为主机和端口）。同名配置会被覆盖。之后在连接栏最左侧的下拉框选择即可一次填入。

配置保存地址、端口、安全策略与模式、超时、用户名、证书路径和断线自动重连，**不保存密码**。切换到用户名不同的配置时，已输入的密码会被清空，避免发给另一个账号。选中配置后点击菜单“连接 › 删除当前连接配置”并确认即可删除。

### 连接记录

每次连接都保存在记录数据库中：时间、地址、安全策略与模式、账号、结果（成功、失败及原因、重连成功）、服务器产品与版本、连接时长，以及连接时读到的服务器信息（命名空间、会话诊断等）。点击连接栏的时钟按钮（或菜单“连接 › 连接记录”）打开：

- “显示”可选当前地址或全部连接，最新的在上；点击一条查看完整设置和服务器信息。
- “填入”把该连接的地址、端口、安全策略、模式和用户名填回连接栏，“连接”同时连接；密码不保存，须重新输入。
- “查看日志与报文”打开该次连接的运行日志和请求记录，程序关闭后也能查看。

### 断线自动重连

“断线自动重连”默认勾选（在“连接设置”和“连接”菜单中）。连接后程序每秒检查连接状态，每 5 秒读取一次服务器状态作为心跳（执行其他读写任务时跳过）。服务器断开连接，或连续 2 次心跳或请求超时，即判定连接中断：

- 勾选自动重连时，状态显示“自动重连中…”，按 2 秒、4 秒、6 秒……（最长 30 秒）的间隔用相同设置重连，直到成功；结果表保留，重连前的节点清单轮询或自动刷新自动恢复。
- 未勾选时，状态显示“连接失败”，须手动重新连接。

重连产生新的连接，写入对话框中每次写入仍须勾选“允许写入”。重连期间点击“断开”或连接其他服务器即停止重连。

### 服务器信息

连接后程序读取服务器的标准 Server 对象，右上角显示产品名称和版本。点击菜单“连接 › 服务器信息”查看并可复制：

- Endpoint 和所用安全策略；
- 产品、厂商、版本、构建号与构建日期、产品 URI；
- 运行状态、启动时间、服务器时间；
- 会话诊断：当前会话数、累计会话数、拒绝会话数、当前订阅数；
- 已连接客户端：客户端应用名称、会话名称、连接时间；
- 命名空间表：`ns=0`、`ns=1`……对应的 URI，可据此确认 NodeID 的命名空间编号。

会话诊断和客户端列表取决于服务器是否启用诊断，未提供时显示“服务器未提供或未启用”。

### 连接数测试

点击菜单“连接 › 连接数测试”。它按当前地址、安全策略和账号依次建立会话并保持，直到服务器拒绝或达到所选上限，随后全部关闭，报告服务器同时接受的会话数。测试会短时间占满服务器会话，可能影响 viSCADA 等其他客户端，请在测试环境或确认允许后执行。

## 基准点位

基准点位是一个已知能正常取数的点位，用来快速判断“服务器是否还在正常提供数据”。

设置：在“单点验证”中验证一个点位，结果为 GOOD 后点击“设为基准点位”。基准点位按 Endpoint 保存在本机（本机演示共用一个），下次连接同一服务器时自动使用。

使用：每次连接和自动重连成功后程序自动读取基准点位，标题栏显示“基准点位 名称：质量 = 值 · 时间”，GOOD 为绿色，BAD 或读取失败为红色。点击刷新按钮可随时再检测，点击清除按钮删除。基准点位的读取不改变结果表。

连接正常但基准点位变为 BAD，通常是设备通讯中断（如 BadNoCommunication）而非 OPC UA 连接问题。

## 单点验证

单点验证读取一个点位的值、数据类型和读写权限，只更新该点结果，其他结果和节点清单保留。它在左栏“单点验证与写入”中；旁边的“写入…”按钮为该点位打开写入对话框，见“写入与读回”。

1. 在输入框输入 NodeID（如 `ns=2;s=Counter`）或 viSCADA 属性标识（如 `2::s::Counter::DINT`）。也可点击下拉按钮，从当前结果列表的前 100 个点位中选择；下拉列表随结果区的筛选和搜索变化，先搜索再选择最方便。
2. 选择类型（默认 Auto，按服务器类型读取）和数量（数组元素数）。从下拉列表、结果表或树状视图选择点位时自动填入其类型；输入属性标识时类型取自属性标识，数量为 1。
3. 点击“单点验证”或按回车。

结果卡片显示 NodeID、名称、类型与读写权限、值、质量、执行状态和时间，以及该点的 viSCADA 属性标识和读写模式（1 只读 / 2 读写）。点击“复制属性标识”可直接粘贴到平台。

### viSCADA 属性标识验证

输入属性标识验证时，结果卡片额外显示“属性标识校验”：

- 通过：节点存在，属性标识中的数据类型与服务器一致。
- 不通过：说明原因，例如“服务器上不存在该节点”（命名空间或标识写错）、“数据类型不符：属性标识为 REAL，服务器为 Double，应为 LREAL”、“节点为数组”、“viSCADA 不支持 OPC UA 类型 DateTime”。
- 建议属性标识：按服务器实际类型生成的正确属性标识，可复制后替换平台中的错误配置。

属性标识格式为 `namespace::类型::标识::数据类型`，类型为 i（数字）、s（字符串）、g（GUID）、b（字节串）。数据类型对应关系：BOOL=Boolean，SINT=SByte，USINT/BYTE=Byte，INT=Int16，UINT/WORD=UInt16，DINT=Int32，UDINT/DWORD=UInt32，LINT=Int64，ULINT/LWORD=UInt64，REAL=Float，LREAL=Double，STRING/WSTRING=String；CHAR、WCHAR 不核对类型。

## 节点清单与轮询

节点清单每行一个 NodeID 或 viSCADA 属性标识，可混合填写；浏览页点击变量会追加到清单。设置类型、数量后点击“读取清单”读取一次，或设置“轮询间隔”（不小于 100 ms）后“开始轮询”，点击“停止轮询”结束；单次读取失败不中断轮询。属性标识行按其自身数据类型读取。轮询以清单结果替换结果表；只想持续更新已读到的点位（如全量读取的结果）时，用结果区的“自动刷新”。

## 全量读取

“全量读取”中的“父节点”决定范围，可直接输入，也可点击右侧下拉按钮选择：`i=85`、连接的服务器的各命名空间（`ns=1`、`ns=2`……）和最近用过的 10 个父节点。点击“全量读取”逐级浏览其层级引用下的全部变量，再连同数据类型和读写权限一起读取；节点浏览页也提供“读取此节点下全部变量”。

- `i=85`：Objects，服务器的全部对象。
- 某个设备或文件夹的 NodeID，如 `ns=2;s=Channel1.Device1`：只读该设备。
- 只填命名空间，如 `ns=2`（也可输入全角 `ns＝2`）：读取 Objects 下命名空间 2 的全部变量，只沿该命名空间的节点逐级浏览，不浏览命名空间 0 中庞大的 Server 对象，结果范围显示为 `ns=2`。

在“连接设置”勾选“连接后自动全量读取”后，每次连接成功即按此父节点自动读取。

全量读取最多 60,000 个变量、100,000 个节点，按 50,000 点设计。浏览一次请求多个节点；读取首批 100 点，服务器响应快时逐步加大到每批 5,000 点，每批之间留 20 ms 间隔，单条消息控制在约 0.5 MB 内。服务器拒绝（操作数或报文超限）时立即减半，超时或资源不足时等待 0.5 s 后减半重试。

全量读取会记录每个变量的浏览路径，树状视图按此路径分层显示。点击“停止读取”保留已取得结果，未读点标记为 NOT_READ，范围显示未完成。

## 节点浏览与节点搜索

“节点浏览”从 `i=85`（Objects）开始；父节点填写 `ns=2` 时列出 Objects 下命名空间 2 的节点。父节点同样可从下拉列表选择命名空间或最近用过的父节点。点击对象的名称列填入父节点，再点击“浏览子节点”；点击变量的名称列追加到节点清单并填入单点验证。NodeID 必须包含正确命名空间，例如 `ns=2;s=Counter`，保留大小写、空格和逗号。

点击“选择”列勾选节点，可多选或点击“全选”，再点击“读取选中节点”：对象读取其下全部变量，变量读取自身。选择跨文件夹保留，点击“清除选择”清空。

### 搜索节点

不知道点位在哪个文件夹时，在“搜索”框输入关键字，点击“搜索节点”：程序在父节点下逐级浏览，列出显示名称、浏览名或 NodeID 匹配的对象和变量，替换浏览列表，下方显示已浏览和找到的数量。

- 模糊：输入一个或多个关键字（空格分隔），不区分大小写，每个关键字出现在任一字段即可，如 `一号站 温度`。
- 精确：与显示名称、浏览名、NodeID 或标识部分完全一致，也可输入属性标识。

父节点同样可填 `ns=2`，只在该命名空间中搜索。搜索范围上限与全量读取相同（100,000 个节点），大型服务器请先选择较小的父节点；可点击“停止”中止。找到的节点可勾选后“读取选中节点”。

## 查看结果

### 工具栏

结果区工具栏只有一行：折叠左栏按钮、搜索框、清除按钮、模糊 / 精确、筛选、视图、自动刷新与间隔、写入、导出。“导出”下拉中有“导出 CSV”“导出 viSCADA 属性表”“复制结果”，菜单“文件”中也有同样的操作。

### 搜索与筛选

结果区工具栏的搜索框输入关键字即时筛选点位：

- 模糊：多个关键字用空格分隔，不区分大小写，每个关键字出现在 NodeID、名称或浏览路径中任一处即可。如 `热力站 供水` 找到一次供水温度。
- 精确：与 NodeID、名称或标识部分（如 `Counter`）完全一致；也可输入属性标识或全角 `ns＝2；s＝…` 形式的 NodeID，找到对应点位。

点击清除按钮清空搜索。“筛选”按质量和状态过滤，与搜索同时生效：全部、GOOD、BAD、UNCERTAIN、不存在（BadNodeIdUnknown / BadNodeIdInvalid）、可写（控制点位）、含中文、请求失败、解析/类型错误、未读取。统计行显示“显示 N / 共 M”、GOOD、BAD 和其他不为零的计数，同一行右侧为最近的读取状态。

### 视图

“视图”下拉（或菜单“视图”）可切换四种视图，搜索、筛选和排序对所有视图生效：

- 表格：列出 NodeID、名称、类型、读写、值、质量 / 状态码、时间、执行状态 / 错误。质量列 GOOD 绿、BAD 红、UNCERTAIN 橙；读写列蓝色为可写的控制点位；执行状态列橙色为请求、解析或类型错误。时间为源时间，没有时依次取服务器时间和读取时间。行间隔着色，过长的内容以“…”截断。
- 排序：点击表头按该列升序排序（▲），再点降序（▼），第三次取消。值列按数值大小排序，数值排在文字前；质量列按 BAD、UNCERTAIN、UNKNOWN、GOOD 排序，问题点位在前。
- 树状：按层级查看数据。全量读取或读取选中节点的结果按浏览路径分层；其他结果按命名空间和字符串标识中的 `.`、`/`、`\` 分层，如 `ns=2;s=热力站.一次供水温度` 显示在 ns=2 → 热力站 下，`Channel1.Device1.Tag1` 显示在 Channel1 → Device1 下。各行按列对齐：文件夹显示其下点位数，含 BAD 点时以红色标出数量；点位显示值（按质量着色）、类型、读写、质量和 NodeID。点击“展开全部”“折叠”整体展开或收起；200 点以内的结果自动展开第一层，搜索后自动展开含匹配点位的文件夹（500 点以内）。

- 卡片：每个点一张卡片，大字显示值（按质量着色，刚变化的值为蓝色），下方为类型、读写、质量和时间，适合像监视画面一样盯住一组点位；可写点位的卡片右上角有写入按钮。
- 趋势：每个数值点位一张图，按时间轴绘制所选范围内的值（工具栏选“10 分钟”“1 小时”“8 小时”“24 小时”），按自身范围缩放，并显示当前值、样本数、最小值和最大值；中间停止采样（如程序关闭）的时段留空。点击一张图放大查看，显示时间轴、平均值和最新时间，可“复制数据”。

趋势数据来自记录数据库：每次读取（自动刷新、轮询、全量读取等）为最多 1000 个数值点位记一个样本，优先记录当前显示的点位，BAD 读数不计入；数据压缩保存，图表显示时从数据库读取所选范围，程序重启或切换范围后仍能看到之前的记录。勾选“自动刷新”即可持续积累趋势。

在任一视图中点击点位，即填入单点验证并显示其详情和属性标识；在表格中点击可写点位的“值”直接打开写入对话框。

### 自动刷新

勾选结果区的“自动刷新”并选择间隔（1–30 秒），程序按间隔重新读取结果中的全部点位，原位更新数值、质量和时间，保留名称、浏览路径、类型和读写权限；状态行显示“自动刷新 · N 点 · 时间”。5000 点以内时，刚变化的值以蓝色标出 3 秒。取消勾选，或单点验证、读取清单、全量读取、开始节点清单轮询、断开连接即停止，之后重新勾选即可；断线自动重连后自动恢复。

### 质量与执行状态

点击统计行前的“?”按钮（或菜单“帮助 › 质量与统计说明”）查看每项计数的含义与处理办法。

- GOOD：服务器提供的正常 OPC 质量。
- BAD：服务器提供的错误质量，保留原始状态码和错误。
- UNCERTAIN：服务器质量不确定。
- UNKNOWN：未收到该点 DataValue。

执行状态单独显示：READ 已读取，REQUEST_FAILED 请求失败，NOT_READ 尚未读取，PARSE_FAILED / TYPE_MISMATCH 为解析失败或类型与所选类型不符。“读写”列显示只读、读写、只写，读写和只写为控制点位。

## 导出

导出始终按当前的筛选和搜索进行，导出点击时的快照，轮询中的后续变化不影响已导出文件。

### 导出 CSV

使用 UTF-8 BOM，Excel 可直接打开中文。包含 Endpoint、NodeID、类型、值、质量、状态码、读取 / 源 / 服务器时间、错误、显示名称、任务状态、执行状态、任务 ID、父节点范围、范围完整和读写权限。64 位整数以文本保存，可能被 Excel 当作公式的文本加单引号保护。

### 导出 viSCADA 属性表

生成平台“设备类属性信息”表格，填写“属性标识”“属性名称”“读写模式”（1 只读 / 2 读写）和“数据类型”，其他列留空。属性名称取点位的显示名称，没有时取标识的最后一段（如 `Line1.Temp` 取 `Temp`）；数据类型按平台代码填写：整数 1、浮点数 2、双精度浮点数 3、字符 4、布尔 6。导出选项显示点数，有不能导出的点时同时显示“跳过 N 个”。

- 有筛选或搜索时，第一项“当前列表”导出结果区正显示的点位。
- 其余选项：全部点位、仅 GOOD 点位、仅控制点位、仅含中文点位；有搜索时这些选项也只包含搜索到的点位。例如先搜索“热力站”，再导出“仅控制点位”，即得到热力站的全部控制点位。

数组和平台不支持的类型（如 DateTime、ByteString）跳过并在完成后列出；超过 60 个字符的属性标识会提示。

### 导入属性表验证

“导入属性表验证”读取平台导出的属性表（或另存后的 xlsx），按“属性标识”读取每个点，结果以“属性名称”命名。筛选 BAD、不存在可找出问题点；TYPE_MISMATCH 表示属性标识中的数据类型与服务器不一致，点击该点，单点验证卡片即显示按服务器类型生成的正确属性标识。控制点位点击其“值”即可写入并读回验证。

## 写入与读回

默认只读。写入都在“写入点位”对话框中进行，打开方式：

- 在表格中点击可写点位的“值”；
- 在卡片视图点击可写点位卡片上的写入按钮；
- 在任一视图选中点位后，点击结果区工具栏的“写入”（或菜单“读取 › 写入选中点位”）；
- 在“单点验证与写入”中输入 NodeID 后点击“写入…”，可写入还未读取的点位。

对话框显示 Endpoint、NodeID、名称、类型和当前值，写入值预先填入当前值；Boolean 点位直接选 true / false，其他类型输入标量或 JSON 数组（如 `123`、`中文文本`、`[1,2,3]`）。类型须明确（不能为 Auto），未读取的点位取单点验证中选的类型。勾选对话框中的“允许写入”后点击“写入并读回”，下方显示服务器确认和独立读回结果，“当前值”同时更新；每次写入后“允许写入”自动取消，对话框保持打开，可继续写入。

服务器确认与独立读回分别显示；UNKNOWN 不自动重发。写入只更新该点结果，不覆盖其他结果。

## 中文点位

NodeID 可以包含中文，例如 `ns=2;s=热力站.一次供水温度`。读取、写入、浏览、搜索、CSV 和属性表导入导出都原样保留中文。用中文输入法输入的全角 `＝`、`；`（如 `ns＝2；s＝热力站.温度`）自动转换为半角，标识本身的字符保持不变。

本机演示提供三个中文点位：`ns=2;s=热力站.一次供水温度`（只读）、`ns=2;s=热力站.循环泵启停`（可写）和 `ns=2;s=热力站.站点名称`（只读）。

## 后台任务

全量读取、导入和导出在后台运行，结果页显示进度条，点击“取消”或“停止读取”可随时取消；取消或失败的导出会删除未完成文件。搜索节点的进度显示在浏览页，点击“停止”取消。任务运行时可继续查看、搜索和筛选结果。

## 通讯与日志

“通讯与日志”页列出最近 256 条服务级请求（READ / WRITE / BROWSE），最新的在上：时间、请求号、方向（TX 发出 / RX 响应）、操作、状态、耗时、目标与错误；异常为红色。

- “筛选”可选全部、异常、READ、WRITE、BROWSE；“搜索”按 NodeID 或错误查找。上方统计显示条数、异常数和响应的平均、最长耗时。
- 点击一条记录，左下“请求详情”列出它的目标（批量请求显示前 100 个）及各点的质量、值或写入结果。右下为运行日志，可“复制日志”。
- “历史日志”显示记录数据库中最近 2000 行运行日志（含以前运行和其他窗口的日志）；“连接记录”打开连接记录，可查看任一次连接的日志与报文。
- “清空显示”隐藏此前的记录，便于观察新的请求；“复制 JSON”和“导出 CSV”只包含当前显示的记录。

## 通讯记录与更新

请求与结果（报文）、运行日志、连接记录和趋势样本都保存在本机 SQLite 记录数据库中（%AppData%\OPCUAAIStudio\records），按天分文件，每个文件不超过 50 MB，写满换下一个文件；记录目录合计超过约 2 GB 时自动删除最旧的文件。批量请求保存全部点位的目标和结果，较大的内容和趋势样本压缩保存（稳定的数值每个样本约 1–3 字节）；磁盘写入跟不上时，批量请求暂时只保存前 100 个点。心跳和服务器信息读取不记入报文。

程序启动后在后台检查新版本，发现时连接栏右侧出现“新版本”按钮；也可点击菜单“帮助 › 检查更新”。通讯记录目录在菜单“文件 › 打开记录目录”和“帮助 › 关于”中。确认后下载发行包，按 SHA256 校验后替换程序文件，提示重启。安装目录不可写时请手动下载。

## 常见问题

- **连接失败“服务器未提供所选安全策略”**：点击“发现端点”，点选服务器实际提供的端点。
- **能连接但读不到点位（BadNodeIdUnknown）**：命名空间编号或标识错误。查看“服务器信息”的命名空间表，或用“搜索节点”按名称查找正确的 NodeID。
- **TYPE_MISMATCH**：所选类型或属性标识中的数据类型与服务器不符。类型选 Auto 重新验证，或按单点验证给出的建议属性标识修改。
- **搜索服务器找不到**：确认搜索范围和端口，检查防火墙；服务器在其他网段时选“指定 IP 或网段”填写其地址；服务器只监听本机地址时只能在服务器本机找到。
- **搜索服务器很慢或电脑变卡（0.6.1 及更早）**：电脑开着 TUN 模式的代理软件时，旧版本的连接会经过代理，每个端口都像是开放的。0.7.0 起本机网段内的连接从网卡自身地址发出，并只对有回应的主机尝试全部端口。
- **趋势图是空的**：趋势在每次读取时记录，勾选“自动刷新”积累数据；切换时间范围会从记录数据库重新读取。
- **不知道点位在哪个命名空间**：全量读取父节点填 `ns=2`（或 `ns=3` 等）逐个尝试，或查看“服务器信息”的命名空间表。
- **频繁自动重连**：检查网络质量，适当加大“超时”；服务器会话数满时可用“连接数测试”确认上限。
- **基准点位 BAD 而连接正常**：服务器与下位设备通讯中断，请检查 PLC 或采集通道。

## 1. 用户需求与产品目标

明确需求：帮助文档解释点位读取；支持单独手动验证一个点；支持全量读取点位；导出点位并区分 GOOD 与 BAD；参考成熟 OPC UA 客户端与模拟服务器；后续以公开独立仓库发布。

目标用户为现场调试、数据对接、软件开发与培训人员。主要任务是连接明确的服务器，找到变量，检查读取结果与质量，保存可以复核的点位报告；进一步支持连续监测、协议能力验证和可重复的模拟场景。

产品保留 Go + Fyne 桌面、共享通讯服务和 CLI 路线。首先交付 Windows x64；其他平台逐步形成独立构建和验证结果。

## 4. 首期核心流程与数据规则

### 4.1 单点验证

入口：输入一个 NodeID，或从浏览树/结果表选中变量，点击“单点验证”。默认 Auto 读取服务器当前值，返回类型、值、原始 StatusCode、源时间、服务器时间、客户端接收时间及错误。

同一连接下已有该点则更新行；没有该点则追加。验证过程中保持其他结果。手工填写不存在的 NodeID 也形成可导出的失败结果。开始手动检查时停止同一工作区的轮询任务，防止旧轮询覆盖检查报告。

“读取成功”与“测量值符合业务期望”分开表达。0.2 验证可读取性和质量；后续点表中填写期望值、容差后才能给出业务核对结论。

### 4.2 读取清单

每行一个完整 NodeID。浏览添加变量时支持追加与去重，不清空已经选择的清单。类型默认为 Auto；明确类型用于额外的类型核对。

所有输入先进行格式校验，逐行给出错误位置。读取按批次执行，保留各节点的独立结果；一个节点 BAD 不阻止同批其他节点的正常结果。

### 4.3 全量读取

默认从用户选择的父节点开始，也可明确选择 Objects（`i=85`）。全量表示该范围内通过层级引用可发现的所有变量，包括变量下的属性变量；不读取对象的 Value，不沿非层级引用无限展开。

流程：选择范围 → 浏览与发现 → 生成去重点表 → 分批读取 → 汇总 → 筛选/导出。记录父节点、开始/结束时间、发现节点数、变量数、已完成数、未完成原因。

同一会话内按规范化 NodeID 去重，防止循环引用。浏览分页继续到无 continuation point；取消或失败时释放 continuation point。跨服务器引用不自动连接其他服务器，标记该引用并由用户显式打开目标连接。

默认每批 100 点；读取并使用服务器提供的操作上限，不支持读取上限时采用保守默认值。遇到可识别的批量上限错误减小批次；通讯中断时终止本轮并保留已得到结果。故障后未尝试的节点标记为未读取，不伪装为服务器返回 BAD。

首期默认遍历上限为 10,000 个唯一节点（包含对象与变量），界面明确显示该限制。达到上限则标记“范围未遍历完成”并建议分支读取。后续提供 1,000～100,000 的显式配置和大规模测试，不能用固定上限后的部分结果声称“全量完成”。

任务支持停止；任务取消应结束调度并取消当前请求，释放该任务资源。保持连接是否可继续使用由实际会话状态判断。再次读取由用户触发。

### 4.4 OPC 质量与执行状态

| 维度 | 状态 | 含义 | 表现 |
| --- | --- | --- | --- |
| OPC 质量 | GOOD | 服务器 DataValue 的质量为 Good | 绿色文字/标记，保留原始状态码 |
| OPC 质量 | BAD | 服务器 DataValue 的质量为 Bad | 红色文字/标记，显示具体状态名称 |
| OPC 质量 | UNCERTAIN | 服务器返回不确定质量 | 橙色，独立筛选，不并入 GOOD |
| OPC 质量 | 未知 | 没有收到可判断该点质量的 DataValue | 中性标记，状态码留空 |
| 执行状态 | 已读取 | 得到该点 DataValue | 值和质量分别显示 |
| 执行状态 | 请求失败 | 会话、网络、批次或客户端处理失败 | 显示失败层级与错误；不伪造节点质量 |
| 执行状态 | 未读取 | 仍未执行、停止或任务中断后的剩余项 | 灰色，保留 NodeID 和原因 |
| 业务核对 | 一致/不一致/未核对 | 与用户给定期望值的比较 | 后续点表功能提供 |

解析不了复杂类型时，保留服务器的原始质量，另列“解析失败/类型尚不支持”。输入类型与服务器类型不符，也属于客户端类型核对结果，不能覆盖真实 OPC 质量。

界面分别统计质量数量和执行状态数量，这两个维度不强行相加成同一个总数。只有全部范围发现完成且每个变量都有读取尝试时，任务才显示“读取完成”；完成不等于全部 GOOD。

筛选按钮：全部、GOOD、BAD、UNCERTAIN、请求失败、未读取。高级筛选可以同时选择质量和执行状态。

### 4.5 导出

0.2 提供 UTF-8 BOM CSV，可选择全部、GOOD、BAD、UNCERTAIN、请求失败或未读取。筛选导出范围在保存前显示数量。导出冻结当前快照，不在保存时偷偷重新读取服务器。

| 字段 | 说明 |
| --- | --- |
| Connection / Endpoint | 点位所属连接及实际服务器地址 |
| NamespaceURI / NodeID | 命名空间 URI（取得时）及当前 NodeID；早期 URI 缺失时明确留空 |
| BrowsePath / DisplayName | 当前已取得的路径、名称；未取得不推测 |
| DataType / Value | 明确类型及值；64 位整数以十进制字符串保留 |
| Quality / StatusCode / StatusName | OPC 原始质量及状态信息；未知时留空状态码 |
| ReadState / CheckResult / Error | 执行状态、业务核对结论和错误 |
| ClientTime / SourceTime / ServerTime | ISO 8601 时间；缺失时间留空 |
| RootNode / ScanComplete / RunID | 全量检查范围、遍历完整性及任务标识 |

逗号、换行与双引号使用标准 CSV 编码。Excel 友好导出对可能触发公式的文本进行保护；后续 JSON 导出保留原始文本用于程序处理。CSV 导入规则对应处理保护前缀，保证往返可解释。

原始 NodeID 不跨服务器直接匹配；重连后命名空间索引可能改变，后续项目与报告以 NamespaceURI 加标识符保存稳定身份，并在当前连接解析索引。

保存失败、文件被占用或磁盘空间不足应明确报错。能采用本地路径时先写临时文件再替换，避免破坏已有报告。

## 5. 各模块详细设计

### F01 工作区与项目

保存连接配置、点表分组、监控组、视图布局和最近打开项目；支持新建、打开、另存为及导出不含凭据的项目文件。项目带格式版本和迁移规则。打开项目后展示连接但不自动写设备；恢复监测需显示将启动的连接与监控组。

验收：项目往返后连接归属、点位身份、分组和布局一致；旧格式可读或给出明确迁移说明；文件损坏不覆盖正常项目。

### F02 多服务器连接

每个连接拥有独立会话、任务、浏览缓存、订阅及记录。服务器树展示未连接、连接中、已连接、重连中与失败。右侧视图始终显示连接别名和 Endpoint；同名 NodeID 不跨连接合并。

支持单独连接、断开、编辑及移除；移除先列出所属任务和视图。单个连接阻塞或断开不冻结其他连接。自动重连仅恢复显式选择的只读任务或订阅；连接代次变化后旧写入确认失效。

验收：两台测试服务器具有相同 NodeID、不同值时，显示和操作均归属正确；断开其中一台不影响另一台。

### F03 Endpoint、安全模式与认证

连接窗口采用别名、Endpoint、端点发现、安全策略/模式、认证方式、超时。发现结果列表展示服务器实际提供的组合，再由用户选择。连接测试展示发现、TCP、安全通道、会话、认证各阶段结果。

匿名和用户名认证沿用现有能力；用户证书认证安排在安全完善阶段。实际支持的策略取 UI、协议库与测试结果的交集。禁用选项显示原因，不宣称支持全部安全策略。错误不自动改为 None 或匿名。

验收：不匹配的策略、证书或认证得到明确失败；有效参数正常连接；错误日志不含密码。

### F04 证书与信任

提供客户端证书生成/导入、私钥关联、证书详情、到期提示、可信与拒绝列表。详情包含主体、颁发者、有效期、应用 URI、主机名和指纹。首次遇到服务器证书展示证书后由用户决定信任。

按实际实现校验证书链、用途、有效期、服务器应用 URI 与连接主机名。安全功能缺失时列出限制；保留固定证书信任模式。私钥受操作系统支持的安全存储保护。GDS、CRL、ECC 和自动证书轮换作为独立技术验证项目，不由“能导入证书”推导为已支持。

验收：过期、不匹配主机名/URI、未信任或变更的证书产生准确结果；导出项目不包含私钥。

### F05 浏览、搜索与定位

地址空间使用懒加载树，展示节点类别图标、名称与 NodeID。展开后分页加载，具备刷新、返回、前进、复制 NodeID、复制路径、加入点表、进入全量读取。

搜索支持名称、BrowseName、NodeID，可选当前分支或更大范围。提供完整 NodeID 粘贴与结构化输入两种方式；后者分别选择连接、命名空间、标识符类型和值，界面实时显示生成的完整 NodeID。分别显示“已加载节点搜索”和“服务器遍历搜索”，后者有进度与停止。未完成搜索不能显示为“没有这个节点”。GUID、ByteString、含空格和逗号的字符串标识保持原始语义。

验收：分页、循环引用、重复引用和命名空间切换正确处理；从筛选结果定位到实际节点；加载不冻结 UI。

### F06 属性与引用

详情页读取 NodeClass、NodeID、BrowseName、DisplayName、Description；变量追加 DataType、ValueRank、ArrayDimensions、AccessLevel、UserAccessLevel、Historizing、Value 与时间；对象/方法追加其相应属性。

引用页区分正向/反向、引用类型与目标节点。未提供的属性显示“该节点不提供”；无权读取与不存在分开。提供只读属性刷新与复制。

验收：对象、变量、方法属性集合正确；AccessLevel 与当前用户权限分别显示；原始引用可以回到目标节点。

### F07～F09 单点、全量与质量

按第 4 节实施。检查对象按稳定身份绑定；结果包括原始协议信息和客户端执行状态。全量过程只浏览和读取，不创建订阅、不写入、不调用方法。

验收：GOOD/BAD 混合列表逐项保留；UNCERTAIN 独立；单点复查不丢失其他行；停止和故障后报告标记不完整；批次限制、连接变化与循环引用均有测试。

### F10 点表与期望值核对

支持手工清单、浏览多选、CSV 导入；后续增加 XLSX。必需标识列支持 NodeID 或 NamespaceURI 加标识符，其他列为名称、分组、类型、单位、期望值及容差。提供导入预览、行号、错误说明、重复处理及模板导出。

期望值核对按类型进行：整数精确比较、浮点按用户给定绝对/相对容差、字符串按明确的比较规则、数组逐项比较。业务不一致与 OPC BAD 分列。未经用户配置不自动更改单位、缩放或写入期望值。

验收：中文、64 位整数、重复点、混合类型、无效行及数组不静默丢失；给出导入/跳过数量。

### F11 导出与报告

点位快照、检查报告、趋势记录、历史数据、事件、模型分别使用明确格式。CSV 面向 Excel，JSON 面向程序；后续 XLSX 多工作表按质量分类，并附汇总、范围与检查参数。

报告可带版本、任务 ID、连接、父节点、完成状态、统计及操作参数；导出不含密码、API Key 或私钥。可独立导出全部和失败项，便于复测。

验收：导出行数与选定快照、筛选数量一致；未知状态不被写成 GOOD；保存失败不提示成功。

### F12 变量写入

保持默认只读。写入使用独立编辑器，明确显示连接、NodeID、类型、数量、旧值与新值。标量、数组及后续结构均先进行类型验证，再逐次确认；成功响应后独立读回。

批量写入后续作为独立操作：先预览各点变更，再确认，逐点显示结果，明确不具备事务原子性。响应丢失时保留 UNKNOWN，不自动重发。提供只读变量拒绝和用户权限说明。

验收：不确认不能写入；连接变化后旧确认不能执行；成功确认、业务拒绝、结果未知与读回不一致独立显示。

### F13 复杂数据类型

展示枚举值与名称、结构字段树、嵌套结构、数组及维度、ExtensionObject 类型/编码信息。优先只读，保留未知类型的元数据与原始编码；不能解析时显示局部错误，不能显示成正常空值。

结构写入在具备类型定义、编码器与完整测试后开放。编辑某字段前展示完整待写结构，避免默认值覆盖未读取字段。数组分页与大值预览限制单独设置。

验收：结构读写编码可往返；未知字段、空数组、多维数组和超大值有明确显示；保留原始 OPC 质量。

### F14 方法调用

从方法节点读取 InputArguments、OutputArguments、Executable 与 UserExecutable。输入按类型生成编辑控件；展示所属对象、方法标识和参数后确认调用。结果显示服务级、方法级、各参数状态及输出。

方法可能改变设备状态，采用与写入同等级的目标确认和连接代次绑定。结果未知不自动重试；禁止 AI 直接调用。

验收：正常方法、缺参数、错误类型、无权限和响应丢失形成可解释记录；未调用不会产生设备侧动作。

### F15 原生订阅

监控组配置采样间隔、发布间隔、队列长度、DiscardOldest、数据变化条件和死区。显示服务器修订后的实际参数、每点建立结果、通知时间与质量。轮询与订阅模式名称明确区分。

断线后保留最后一次值和时间，并加离线/过期标记，不沿用为最新 GOOD。恢复时记录间隙、订阅是否重建及可能缺失的数据。UI 刷新节流，采集队列满时显示丢弃计数。

验收：值变化、仅质量变化、通知中断、队列满、重连、停止/关闭均正确处理；停止后释放订阅资源。

### F16 实时趋势

数值变量支持多曲线、独立颜色、时间窗口、缩放、暂停、游标、最小/最大/平均值；布尔/枚举使用阶梯展示。单位从服务器或用户配置取得，未经配置不混用量纲。

曲线对 BAD、UNCERTAIN、离线和缺失段作显式标记；绘图降采样与原始记录分开。导出 CSV/JSON 原始样本以及 PNG/SVG 视图，说明图中采用的时间和聚合规则。

验收：质量异常不被平滑成正常曲线；图表暂停不隐式暂停采集；可从游标回到原始样本。

### F17 历史数据

选择变量、时间区间、原始/聚合模式、聚合类型和间隔，执行历史查询；支持服务器分页、停止、表格、图表与导出。只提供服务器实际支持的聚合选项。

服务器历史与本地采集历史分别标注来源。查询本地记录不能冒充服务器 HistoryRead。保留边界值、时间戳、原始质量和聚合标识，明确空结果、无权限与能力不支持。

验收：多页读取、边界、空区间、重复时间、质量异常、取消和历史能力缺失均可复核。

### F18 实时事件、告警与条件

订阅具有事件能力的对象/视图，选择事件字段、类型、严重度、来源和时间筛选。事件表保留 EventID、EventType、Source、Time、Message、Severity；条件追加 Active、Acked、Confirmed、Retain 等可用状态。

确认（Acknowledge）与认可（Confirm）分别提供操作和权限提示，展示条件、事件及注释后逐次确认。开始监控或恢复会话时按能力处理条件刷新；历史保留与当前有效条件分别展示。

验收：事件去重、条件状态更新、刷新、权限拒绝与结果未知准确记录；告警操作不会因双击或筛选误触发。

### F19 历史事件

查询支持事件历史的节点，选择时间、字段与过滤条件，分页取得结果并导出。事件时间与客户端接收时间分开；相同 EventID 的重复来源可解释。

验收：可重现查询参数及范围；实时事件缓存与服务器历史来源明确；取消后释放分页资源。

### F20 图像查看器

对已识别的图像编码/ByteString 变量提供图片预览，展示原始类型、编码、大小、尺寸、质量与时间。支持手动读取或订阅刷新、原图保存及帧冻结。

限制编码数据大小与解码后像素数；非法数据、未知格式、超限或 BAD 质量显示原因。大图刷新与 UI 解耦，保存原始文件与保存当前视图分别提供。

验收：可查看有效样本；坏数据和巨大尺寸不导致程序崩溃；保存不静默修改原始图像内容。

### F21 信息模型、图与 NodeSet

以当前节点为中心显示引用关系，可限制深度、方向、类型及节点数。节点图使用类别图标与文字，支持跳回浏览树，导出 SVG/PNG。

NodeSet 导出保存选定范围的节点、属性、类型及命名空间依赖，列出范围外依赖和不完整原因。导入首先用于离线查看或模拟器，不自动写入现场服务器。提供模型版本、节点增删、类型和引用变化的差异报告。

验收：图循环不会无限展开；NodeSet 有可验证的依赖清单；不同命名空间索引不造成虚假模型差异。

### F22 记录、本地历史与回放

区分通讯审计、点位采样、事件记录三类数据。审计保存服务级请求/结果、连接、节点、错误和耗时；采样保存值、质量和多种时间；事件保留原始字段。按时间/大小轮转，展示记录健康、排队和丢弃数量。

本地回放独立于实时连接，支持播放、暂停、速率、跳转，始终标记“离线回放”。回放驱动显示与后续模拟服务器，不自动向现场设备重放写入或方法。

验收：正常退出排空记录；队列丢弃不被掩盖；本地历史查询与服务器历史准确区分。

### F23 可配置模拟服务器

在现有六节点演示基础上，提供命名空间、对象/变量树、自定义类型、初值、可写性、质量与更新时间配置。CSV/JSON 项目保存模拟节点；后续支持 NodeSet 信息模型。

信号包括常量、递增计数、正弦、方波、三角、锯齿、带种子的随机数和文件回放；配置周期、幅值、偏移、更新间隔。提供 GOOD/BAD/UNCERTAIN 切换、延时、断线及请求错误场景；复杂结构、方法、事件和历史按相应协议模块逐项增加。

界面显示监听地址、实际端口、客户端会话、运行状态和错误。默认回环监听，向外提供服务需明确配置监听接口、安全与用户权限。真实服务器与模拟服务器在连接树中标识清楚。

验收：可用本工具、UaExpert 或 Softing 等独立客户端读取相同的模拟数据；信号可重现；停止后端口、会话与记录释放。

### F24 CLI、自动化与场景测试

沿用现有命令与 JSON 输出，增加按父节点全量检查、质量筛选导出、点表核对和报告。GUI 与 CLI 共用同一任务服务与格式实现，避免质量判断分歧。

约定退出码：成功完成且满足所选检查策略为 0；点位 BAD、核对失败、请求失败或范围未完成为 1；参数/配置错误为 2。是否把 UNCERTAIN 判为检查失败作为显式策略，默认严格检查。

自动化场景绑定明确 Endpoint 与节点清单；默认只读。设备写入和方法操作要求显式参数和可审计的目标配置，不把GUI确认绕过解释为自动化许可。

验收：无 GUI 环境也能完成本机只读回归；退出码与报告一致；64 位数值不丢精度。

### F25 AI 诊断

用户冻结并预览连接信息、状态码、选定点位、日志与统计后，主动发送至配置的 AI 服务。支持解释质量异常、类型不匹配、证书问题和检查报告，给出可定位到证据的建议。

诊断输出注明证据范围，缺少工程单位或物理量依据时不推测工程含义。API Key 不进入项目、普通日志或导出。AI 建议与设备动作隔离；只能由用户在相应操作页确认动作。

验收：实际请求与预览一致；脱敏选项生效；AI 失败不影响读取任务或记录保存。

### F26 帮助、教程和故障指导

内置离线帮助，发行包同时携带可阅读的操作说明。目录覆盖连接、端点/认证/证书、NodeID、单点、清单、全量、质量、导出、写入、订阅及各后续模块。

首期教程使用 Counter、Temperature、Missing 等明确例子：单点 GOOD、不存在节点 BAD、类型核对失败、全量六变量、筛选并导出 BAD、停止任务后解释未完成报告。说明“只读变量”仍可读取，不能仅因不可写就判为 BAD。

提供典型状态码与故障层级说明，连接错误与点位错误分开。帮助页面展示“当前版本已支持”的功能，不沿用参考软件的全部能力作为本软件说明。

验收：新用户按帮助从启动演示到导出报告完成全流程；菜单按钮名称与实际界面一致；离线可打开。

### F27 公开仓库、发行、更新及平台

目标仓库为 `xiaolengWangWang/opcua-ai-studio`，设为公开，使用现有 Git 登录凭据。源码、文档、版本标签、发行说明和二进制建立对应关系；第三方参考软件只保存在忽略的本地目录。

发行包包含 GUI、CLI、模拟器、离线帮助、版本文件；同级提供 SHA-256、构建清单和验证报告。构建清单记录真实源码提交、构建时工作区状态、工具链及产物摘要。下载后校验文件与启动结果，再宣布完成。

更新检查只提供信息和下载入口；不自动覆盖运行中的程序。各平台分别验证 GUI、字体、记录路径、凭据存储与打包。Windows 优先，Linux/macOS 按独立测试结果开放。

验收：公开仓库与正式 release 可匿名访问；下载 SHA-256 对应清单；新机器不需 Go 即可运行 Windows 包；无凭据或现场数据进入公开产物。

### F28 OPC UA 服务器扩展

从模拟服务能力发展为显式配置的 UA 服务器：自定义地址空间、读写权限、认证与证书、方法、数据/事件订阅及后续历史。作为独立服务实例管理，界面标明客户端连接与本机发布方向。

数据源可为模拟值、导入点表或显式映射的外部数据；转发时保留质量与时间，来源离线时改变对外状态。SDK 服务端能力、互操作和可用性验证通过后才进入正式发布。

验收：独立客户端验证发现、浏览、读写、权限与订阅；服务器停机不造成客户端工作区崩溃。

### F29 OPC UA Pub/Sub 扩展

建立独立的发布/订阅配置页：传输、编码、连接地址、PublisherID、WriterGroup、DataSetWriter、DataSet 与字段定义；订阅侧显示数据集、序号、时间、质量、丢包及解码错误。

规划 UDP/UADP 与 MQTT 上的适用编码，分别开展互操作原型；支持矩阵按通过验证的组合列出。元数据缺失时不能把原始字节错误解释为变量值。安全密钥、元数据更新与配置发布单独管理。

验收：与独立发布者/订阅者互通；乱序、丢包、元数据变化和断线有诊断；不将客户端原生订阅标成 Pub/Sub。

### F30 OPC Classic DA 可选扩展

Windows 专用模块，连接配置为服务器 ProgID/CLSID、主机与运行身份。提供服务器浏览、Group/Item、同步读取、异步数据变化、写入、质量和时间。DA 地址与质量码使用自己的规则。

COM 会话与回调在适合的线程/辅助进程中隔离，批次和队列显式控制。界面分别诊断 DCOM 权限、服务器可用性、身份与 Item 错误。远程 DCOM 配置以指导为主，不自动修改系统权限。

验收：本机已知 DA 测试服务器读写及回调正常；UA 会话不受 COM 阻塞影响；非 Windows 明确显示不可用。

### F31 配套规范、RFID 与 AutoID

在通用信息模型浏览之上，根据命名空间 URI、类型与方法定义识别已验证的配套规范。先提供类型、字段与扫描结果视图，再增加与具体模型相符的 RFID/AutoID 方法和事件。

不能仅依据节点名称就判定某设备符合配套规范；识别不到时仍可使用通用浏览。厂商自定义字段保留元数据。具体配套规范版本、设备、方法与测试样例组成支持矩阵。

验收：固定标准模型样例可识别；通用客户端功能仍可用；不支持的规范或版本明确列出。

### F32 数据对接与转发可选扩展

借鉴 OPC Router 的显式点位映射思路，提供源连接/节点、目标、类型转换、触发方式、质量规则和错误策略。先支持报告/CSV 输出，后续按独立需求加入数据库、MQTT 或 HTTP 输出。

默认只对外输出经过明确配置的数据，不自动反向写设备。运行时显示最后成功时间、失败、重试队列与丢弃数；重试必须适配目标幂等性，敏感凭据单独存储。正式长期路由能力作为独立扩展交付。

验收：映射数据、质量与时间可追溯；失败不丢失且不无限重试；未经配置不建立外部连接。

| UI / CLI | 输入、预览、选择、显示、导出入口 | 共享服务行为；UI 线程不执行网络操作 |
| 工作区与连接服务 | 当前项目、多连接、代次、任务取消、监控组 | 0.2 沿用单控制器；多连接阶段才增加会话管理 |
| 检查/浏览/订阅/历史等任务 | 每种能力的明确输入、进度与结果 | 按实际能力增加接口，不先建立空插件框架 |
| 协议适配 | OPC UA SDK、未来 DA/PubSub/Server | 不让 UI 直接依赖协议库返回对象 |
| 类型与报告模型 | 稳定点位身份、值、质量、时间、执行状态 | 原始质量与客户端错误独立；格式带版本 |
| 记录与存储 | 项目、通讯审计、样本、事件、报告 | 项目配置与凭据分离；记录按大小/时间轮转 |

全量检查任务包含 RunID、ConnectionID、Generation、RootNode、阶段、开始/结束、发现数、完成数、取消原因与范围完整性。结果不能跨连接代次混入同一次报告。

多连接、订阅、历史与事件作为后续独立能力增加；现有单连接 Driver 不一次性加入大量未实现方法。复杂数据编解码与协议服务端需分别验证适配库，保留现有已验证代码的可维护性。

### 6.2 数据与身份

点位身份由 ConnectionID、NamespaceURI、标识符类型和值组成；当前 NodeID 用于当前会话的协议访问。别名与 DisplayName 用于显示，不作为唯一键。

值保存类型和维度，整数精度、字节内容、Null 与空数组分别保留。时间以 UTC 持久化、按用户时区显示。原始 StatusCode、读取状态、解析错误与期望值核对结论分别保存。

用户项目、应用日志、记录、证书与凭据目录分离。密码/API Key 只有用户选择安全存储后才保存；导出项目和报告去除这些凭据。模拟数据与现场采样有来源标记。

## 7. 性能、资源及操作边界

| 项目 | 初始设计目标/规则 | 验证方式 |
| --- | --- | --- |
| 点位规模 | 0.2 支持分批清单与默认 10,000 节点遍历上限；后续验证更大范围 | 1,100 点跨批次、10,000 节点、后续 50,000 点场景 |
| UI | 网络在后台；虚拟化列表；任务进度合并更新 | 读取时仍可切页、筛选、停止 |
| 服务端负载 | 限制单连接并发；使用操作上限；浏览和读取可停止 | 小批次上限、慢响应与取消测试 |
| 大值 | 预览长度、数组分页、图像大小分别限制 | 超大字符串/数组/图像不耗尽内存 |
| 连续采集 | 有界队列，丢弃/断档可见；绘图与持久化分离 | 高通知速率与磁盘慢/满场景 |
| 退出 | 取消任务、释放分页与订阅、排空记录、关闭会话与演示 | 关闭后端口、句柄与文件可重新打开 |

写入、方法调用、告警确认分别要求显示目标与逐次确认；连接变化使旧确认失效。对于结果未知的改变状态操作不自动重试。连接和检查仅访问用户明确选择的服务器与范围。

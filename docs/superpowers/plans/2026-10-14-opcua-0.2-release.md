# OPC UA 0.2.0 实现与发版计划

> 执行方式：使用 executing-plans 在当前功能分支执行。用户已通过“发版”授权完成实现、验证、合并和公开发布。

**目标：** 完成精简设计中的点位检查、全量读取、质量筛选、CSV 和离线帮助，发布可运行的 Windows 0.2.0。

**架构：** 复用 Controller 的会话锁和取消机制、现有 OPC UA 浏览分页及 Fyne 控件。CSV 使用标准库；不增加依赖。

**规格：** [精简设计](../specs/2026-10-14-opcua-client-lean-design.md)。

## 全局约束

- 最终图标及版本资源写入后的主程序 EXE 不超过 30,000,000 字节。
- 保留单连接、安全验证、只读默认和写入确认；不实现暂缓功能。
- 全量遍历上限 10,000 个唯一节点，读取默认每批 100 点。
- OPC 原始质量与客户端执行错误分开；不完整结果和范围必须可导出。

## 重点核对

请求失败不能伪装成 BAD；取消不能丢弃已读点；筛选后选择必须定位正确 NodeID；CSV 要保留中文和 64 位精度；连接变化不能混入旧结果。

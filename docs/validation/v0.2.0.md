# 0.2.0 发行验证

本版按 [精简设计](../superpowers/specs/2026-10-14-opcua-client-lean-design.md) 验证常用功能，Windows 主程序限制为 30,000,000 字节。

自动化命令：

```powershell
go test -tags ci -count=1 -timeout 10m ./...
go vet -tags ci ./...
powershell -NoProfile -ExecutionPolicy Bypass -File build/windows.ps1 -Version 0.2.0
OPCUAAIStudio.exe --smoke-test <验证目录>
```

测试覆盖全量 1100 点、多级引用和循环去重、服务器批次上限、取消保留已读及未读点、通讯失败不伪装成 BAD、合法 NodeID 空白、单点结果保留、原始质量、筛选后行选择、浏览追加、CSV 中文/64 位/保存失败和忙碌期间 Enter。

原生烟测验证本机 Counter 42 → 123，写入 CONFIRMED 和独立读回一致；全量六个 GOOD 变量，单独验证一个不存在节点得到 BAD，导出全部与 BAD CSV，保存 SQLite 记录，关闭后释放演示端口。截图用于检查中文、控件与结果展示。

最终发行证据随 Release 上传：`verification-0.2.0.json` 为原生烟测结果，`build-manifest.json` 记录源码提交、版本、主 EXE 字节数及哈希，`SHA256SUMS.txt` 校验 ZIP。发布前须确认清单中的 `dirty` 为 false，主 EXE 版本为 0.2.0，EXE/ZIP 与哈希一致。

本机协议服务器验证不代表现场 PLC 认证；未在烟测中调用线上 AI 服务。订阅、历史、事件、方法、DA 与 Pub/Sub 不在本版范围。

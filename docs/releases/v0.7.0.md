# OPC UA AI Studio v0.7.0

## 搜索服务器

- 修复搜索慢、关闭或停止时卡顿：电脑开着 TUN 模式代理时，旧版本的连接经过代理，每个端口都像是开放的，程序对每个地址都查询端点。现在本机网段内的连接从网卡自身地址发出，不经过代理。
- 先对每台主机尝试第一个端口，再只对有回应的主机（端口开放或应答了 ARP）尝试其余端口，不存在的主机只尝试一次，网段中空闲地址越多，节省的时间越多。
- “主机 / 网段”始终可以修改，改后自动变为“指定 IP 或网段”并记住；文字不再是看不清的灰色。

## 写入

- 去掉左栏的“写入设定值”区域，写入统一在“写入点位”弹窗中进行：点击表格中可写点位的“值”、卡片上的写入按钮、结果栏“写入”，或单点验证旁的“写入…”。
- 弹窗写入后“当前值”随读回更新，可连续写入。
- 修复写入时连接栏地址框变窄：忙碌指示和基准点位改为固定宽度。

## 数据展示

- 趋势视图可选 10 分钟、1 小时、8 小时、24 小时，按时间轴绘制，停止采样的时段留空；数据来自记录数据库，重启或切换范围后仍在。点击一张图放大查看，显示平均值和最新时间，可复制数据。
- 卡片视图中可写点位有写入按钮。
- 统计行前新增“?”按钮，说明 GOOD、BAD、UNCERTAIN、不存在、可写等计数的含义与处理办法（也在“帮助 › 质量与统计说明”）。
- 全量读取和节点浏览的“父节点”可从下拉列表选择：`i=85`、服务器的各命名空间和最近用过的父节点。
- 灰色提示文字和禁用的输入框文字加深，更易阅读。

## 记录数据库

- 运行日志、连接记录和趋势样本存入记录数据库；批量请求的报文保存全部点位的目标和结果（此前只存前 100 个），较大的内容压缩保存，趋势样本按点位分块压缩（稳定的数值每个样本约 1–3 字节）。
- 单个数据库文件仍不超过 50 MB；记录目录合计超过约 2 GB 时自动删除最旧的文件。
- 新增“连接记录”（连接栏时钟按钮、“连接 › 连接记录”、通讯与日志页）：列出以前的连接及其安全、账号、结果、服务器与时长，可一键填入或重连，并查看该次连接的日志与报文。
- 通讯与日志页新增“历史日志”，可查看以前运行和其他窗口的日志。

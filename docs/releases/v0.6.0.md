# OPC UA AI Studio v0.6.0

## 数据展示区

- 结果表点击表头排序（升序 ▲ / 降序 ▼ / 取消）：值列按数值大小，质量列按 BAD、UNCERTAIN、GOOD 让问题点位在前。
- 新增独立的“时间”列（源时间，没有时取服务器时间或读取时间），行间隔着色，过长内容以“…”截断。
- 结果区“自动刷新”：按 1–30 秒间隔重新读取结果中的全部点位，原位更新数值，保留名称、浏览路径、类型和读写权限；刚变化的值以蓝色标出 3 秒；断线重连后自动恢复。
- 树状视图按列对齐，文件夹显示点数并以红色标出其中的 BAD 点数，搜索后自动展开含匹配点位的文件夹。
- 结果区左上角折叠按钮收起左栏，让数据区占满窗口；没有结果时显示操作提示。

## 点位与读写

- 左栏改为可折叠的“单点验证与写入”“节点清单与轮询”“全量读取”“viSCADA 属性表”。
- 写入设定值并入单点验证：点击控制点位自动填入当前值，Boolean 点位直接选 true / false，确认框同时显示当前值和写入值。
- 导出属性表同时填写“属性名称”（显示名称）和“数据类型”（平台代码），导出选项提前显示将跳过的点数。

## 连接

- 连接区精简为两行：连接配置、Endpoint、搜索服务器、发现端点、连接 / 断开；安全摘要（点击展开安全设置）、断线自动重连、保存配置、服务器信息、本机演示和“⋯”菜单（删除配置、连接数测试）。
- Endpoint 可只填 IP 或主机名，自动补全 `opc.tcp://` 和端口 `4840`；下拉列表保存最近 10 个连接。
- 搜索服务器提速：扫描与端点查询并行，找到即显示，按 IP 排序；每个服务器可直接“连接”或“填入”；记住上次的网段和端口。

## 通讯与日志

- 请求记录改为表格，最新在上，可按全部 / 异常 / READ / WRITE / BROWSE 筛选、按 NodeID 或错误搜索，统计响应平均与最长耗时。
- 选中一条查看全部目标及各点结果；可清空显示、复制 JSON、导出 CSV。

## 其他

- 适配 Windows 桌面密度与不同屏幕分辨率：界面更紧凑，窗口大小在退出时保存，屏幕较窄时左栏默认更窄。
- 发布页分开提供：桌面程序单文件 `OPCUAAIStudio-0.6.0-Windows-x64.exe`、命令行工具包 `opcua-tools-0.6.0-Windows-x64.zip`（opcua-cli 与 opcua-sim），以及完整包 `OPCUAAIStudio-0.6.0-Windows-x64.zip`（程序内更新使用）。
- 操作手册同步更新。
- 主程序 EXE：**28.85 MB**，低于 30 MB。

0.4.0 及以上版本可点击状态栏“检查更新”在程序内升级。[下载桌面程序单文件（Gitee）](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.6.0/OPCUAAIStudio-0.6.0-Windows-x64.exe)，或[完整包](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.6.0/OPCUAAIStudio-0.6.0-Windows-x64.zip)解压后运行 `OPCUAAIStudio.exe`。也可从 [GitHub 下载](https://github.com/xiaolengWangWang/opcua-ai-studio/releases/tag/v0.6.0)。

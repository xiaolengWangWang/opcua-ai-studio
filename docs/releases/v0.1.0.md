# OPC UA AI Studio v0.1.0

首个版本：使用 Go + Fyne 的中文 OPC UA 桌面调试工具，提供 Windows GUI、CLI 和本机模拟器。

## 功能

- Endpoint 发现、安全策略选择、匿名及用户名认证、证书配置与固定信任比对。
- 节点浏览与分页、多节点读取、标量及一维数组写入、轮询监测。
- 写入默认禁用，逐次确认后写入并独立读回；未知结果不自动重发。
- 本机演示提供整数、浮点、布尔、字符串、数组和只读节点。
- SQLite 通讯记录、应用日志及由用户主动触发的 DeepSeek AI 诊断。

## 下载与启动

下载 `OPCUAAIStudio-0.1.0-Windows-x64.zip`，解压后运行 `OPCUAAIStudio.exe`。无需安装 Go 或 MinGW。ZIP 同时包含 `opcua-cli.exe`、`opcua-sim.exe` 和使用说明。

Windows x64 需要支持 OpenGL 的图形驱动。可先点击“启动本机演示”，验证 Counter 从 42 写为 123 后独立读回一致。

全量测试和静态检查通过；Windows 发布包实测写入读回一致、浏览 6 个节点、保存 10 条通讯记录，正常退出后演示端口释放。安全连接、浏览分页和未知写入状态已有本机协议测试。

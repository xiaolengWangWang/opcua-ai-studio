# OPC UA AI Studio v0.5.0

## 查找与连接

- 搜索服务器：扫描本机和局域网网段（默认本机各网卡 /24）的常用 OPC UA 端口（4840、4841、4862、4890、48010、49320、53530、62541），列出服务器名称、地址和安全策略，并查询发现服务器登记的其他服务器；点选即填入 Endpoint 和安全策略。
- 发现端点改为列表点选，自动填入安全策略和模式。
- 连接配置：保存、切换、删除常用连接，保存 Endpoint、安全策略、超时、用户名、证书和自动重连，不保存密码。
- 断线自动重连（默认开启）：每秒检查连接、每 5 秒心跳，服务器断开或连续 2 次无响应即按 2–30 秒间隔重连；保留结果，恢复轮询。
- 服务器信息：产品、厂商、版本、运行状态、启动时间、命名空间表、会话诊断和已连接客户端；状态栏显示产品名称和版本。

## 点位验证

- 单点验证可直接输入 viSCADA 属性标识（如 `2::s::Counter::DINT`），校验节点是否存在、数据类型是否一致，并给出按服务器类型生成的建议属性标识；“复制属性标识”一键复制。
- 单点验证卡片独立选择类型和数量，下拉列表从当前结果中选点并自动带出类型；结果卡片显示值、质量、类型、读写权限和读写模式。
- 基准点位：把读数正常的点设为基准点位，按 Endpoint 保存，每次连接和自动重连后自动检测，标题栏显示其质量、值和时间。
- 节点清单也可填写 viSCADA 属性标识。

## 查看与导出

- 结果搜索：模糊搜索支持多个关键字，匹配 NodeID、名称和浏览路径；精确搜索匹配完整 NodeID、名称、标识或属性标识。与质量筛选同时生效，统计显示“显示 N / 共 M”。
- 导出 CSV 与导出属性表按当前筛选和搜索同步导出；属性表新增“当前列表”。
- 树状视图：全量读取结果按浏览路径分层，其他结果按命名空间和标识中的 `.`、`/` 分层，文件夹显示点数，点位按质量着色。
- 结果表新增“名称”列。
- 节点浏览页新增“搜索节点”，在父节点下按名称或 NodeID 逐级搜索，结果可勾选读取。

## 其他

- 状态栏“操作手册”提供完整离线操作手册。
- 轮询遇到单次读取失败继续进行；请求连续超时视为连接中断并自动重连。
- 主程序 EXE：**28.76 MB**，低于 30 MB。

# OPC UA AI Studio v0.2.0

本版补齐常用点位检查流程，Windows 主程序 EXE 硬上限为 30,000,000 字节。

- 单点手动验证：独立 NodeID 输入，只更新对应点，保留其他结果及清单。
- 全量读取：递归浏览指定范围、分页去重、分批读取、进度及停止；最多遍历 10,000 个节点。
- 质量区分：保留服务器 GOOD/BAD/UNCERTAIN 和状态码，执行错误及未读取单独记录。
- 筛选和 CSV：导出冻结快照，带 Endpoint、NodeID、类型、值、时间、错误、任务及范围完整性；中文和 64 位标量整数保护。
- 离线帮助：本机演示、单点、全量、质量与导出操作说明。

下载 `OPCUAAIStudio-0.2.0-Windows-x64.zip`，解压运行 `OPCUAAIStudio.exe`。ZIP 同时含 CLI、模拟器和说明，无需安装 Go 或 MinGW；需要支持 OpenGL 的图形驱动。完整性以同发行页的 SHA256SUMS.txt 和 build-manifest.json 为准。

沿用已有安全认证、写入确认与独立读回、轮询、SQLite 记录和 AI 诊断。订阅、趋势、历史、方法、事件、DA、Pub/Sub、多服务器等暂缓。本版测试基于本机协议服务器，尚未完成现场 PLC 实机验证。

操作说明见 [点位帮助](../../assets/help/points.md)，范围见 [精简设计](../superpowers/specs/2026-10-14-opcua-client-lean-design.md)。

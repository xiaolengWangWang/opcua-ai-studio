# OPC UA AI Studio v0.3.0

- 全量读取按 50,000 点设计：批量浏览、自适应分批（100 起步，最多 5,000 点/批）、批间限速，服务器拒绝或超时自动减半；本机模拟器 50,000 点浏览 + 读取 + 类型与读写权限约 3.5–7 s。
- viSCADA 属性表：导出（全部 / 仅 GOOD / 仅控制点位，填写属性标识与读写模式）与导入验证（GOOD / BAD / 不存在 / 类型不一致）。
- 识别可写控制点位，导入后可写入并读回验证；写入读回不再覆盖结果列表。
- 节点浏览支持多选、全选读取；新增连接数测试；新增“不存在”“可写（控制点位）”筛选。
- 导入、导出、CSV 后台运行，显示进度并可取消；结果表按需渲染，50,000 点不卡顿。
- 修复程序内“读取帮助”在加密构建机上显示乱码。
- 主程序 EXE：**28.312 MB**，低于 30 MB。

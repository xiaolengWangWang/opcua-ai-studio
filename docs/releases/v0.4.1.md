# OPC UA AI Studio v0.4.1

- 中文点位：NodeID 可以包含中文（如 `ns=2;s=热力站.一次供水温度`），读取、写入、浏览、CSV 与 viSCADA 属性表导入导出都原样保留。
- 中文输入法输入的全角 `＝`、`；`（如 `ns＝2；s＝热力站.温度`）自动转换为半角，标识本身保持不变。
- 新增“含中文”筛选和统计；“导出属性表”新增“仅含中文点位”，导出全部点位时提示其中含中文的属性标识数量。
- 本机演示新增三个中文点位：一次供水温度（只读）、循环泵启停（可写）、站点名称（只读）。
- 主程序 EXE：**28.41 MB**，低于 30 MB。

0.4.0 用户可点击状态栏“检查更新”在程序内升级。[下载 Windows x64 发行包（Gitee）](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.4.1/OPCUAAIStudio-0.4.1-Windows-x64.zip)，解压运行 `OPCUAAIStudio.exe`。也可从 [GitHub 下载](https://github.com/xiaolengWangWang/opcua-ai-studio/releases/download/v0.4.1/OPCUAAIStudio-0.4.1-Windows-x64.zip)。

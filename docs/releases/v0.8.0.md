# OPC UA AI Studio v0.8.0

## 新增 Linux Web 版

- 解压后运行 `./opcua-ai-studio`。网页、OPC UA 服务和 SQLite 已打包进同一个可执行文件，目标机无需安装 Go、Node.js、Docker 或数据库服务。
- 有桌面时会尝试打开默认浏览器，终端同时显示访问地址。默认监听 `http://127.0.0.1:8787/`，无桌面时可使用 `-no-browser`，从本机通过 SSH 端口转发访问。
- 网页支持端点发现、匿名或用户名认证、PEM 证书安全连接、节点浏览、批量读取、全量读取、自动刷新、写入确认与读回，以及运行日志。可点击“启动演示”，用 `ns=2;s=Counter` 体验读取。

## 安装包

在银河麒麟上运行 `uname -m`，按结果选择 Linux 安装包。龙芯 LoongArch64 包要求 Linux 内核 5.19 或更新。[Go 的 Linux 内核要求](https://go.dev/wiki/Linux)

| 平台 | 文件 |
| --- | --- |
| Linux `x86_64` | `OPCUAAIStudio-0.8.0-linux-amd64.tar.gz` |
| Linux `aarch64` | `OPCUAAIStudio-0.8.0-linux-arm64.tar.gz` |
| Linux `loongarch64` | `OPCUAAIStudio-0.8.0-linux-loong64.tar.gz` |
| Windows x64 桌面程序 | `OPCUAAIStudio-0.8.0-Windows-x64.exe` |
| Windows x64 完整包 | `OPCUAAIStudio-0.8.0-Windows-x64.zip` |
| Windows x64 命令行工具包 | `opcua-tools-0.8.0-Windows-x64.zip` |

发行文件的校验值见 `SHA256SUMS.txt`。Windows 用户可通过“帮助 › 检查更新”升级，或下载完整包后解压运行 `OPCUAAIStudio.exe`。

三个 Linux 架构均已交叉构建，网页已在本机浏览器中完成演示验证。银河麒麟实机运行待验证。

# OPC UA AI Studio v0.7.1

## 获取 endpoint-host

- “连接设置 › 发现端点”显示服务器返回的 `endpoint-host`，点击“复制 endpoint-host”可复制 `endpoint-host=admin-PC` 等参数。
- 连接后，“连接 › 服务器信息”也显示当前所选端点的 `endpoint-host`。
- 参数取自服务器返回的端点 URL。例如使用 IP 连接，服务器返回 `opc.tcp://admin-PC:49320` 时，提取结果为 `admin-PC`。
- CLI 的 `endpoints` 输出增加 `endpoint-host`；JSON 输出增加 `endpoint_host` 字段。

0.4.0 及以上版本可通过“帮助 › 检查更新”升级。[下载桌面程序单文件（Gitee）](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.7.1/OPCUAAIStudio-0.7.1-Windows-x64.exe)，或[完整包](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.7.1/OPCUAAIStudio-0.7.1-Windows-x64.zip)解压后运行 `OPCUAAIStudio.exe`。也可从 [GitHub 下载](https://github.com/xiaolengWangWang/opcua-ai-studio/releases/tag/v0.7.1)。

# OPC UA AI Studio v0.4.0

- 软件内更新：启动后在后台检查 Gitee（失败时改用 GitHub）的最新版本，状态栏提示；确认后下载、按 SHA256 校验、替换程序文件并重启，也可点击“检查更新”。0.3.0 及更早版本需手动下载一次 0.4.0。
- 新布局：点位页左侧为分组操作栏，右侧结果表占满窗口高度，表头固定，滚动 50,000 行时始终可见；连接区收为一张卡片，底部为状态栏。
- 新配色：工业蓝主题，浅色与深色均通过 WCAG AA 对比度检查；结果表按质量着色（GOOD 绿、BAD 红、UNCERTAIN 橙），可写点位蓝色标出，统计栏分色显示。
- 属性表导出的默认文件名改为“全部 / GOOD / 控制点位”。
- 主程序 EXE：**28.39 MB**，低于 30 MB。

[下载 Windows x64 发行包（Gitee）](https://gitee.com/xiaolengwangwang/opcua_ai_studio/releases/download/v0.4.0/OPCUAAIStudio-0.4.0-Windows-x64.zip)，解压运行 `OPCUAAIStudio.exe`。也可从 [GitHub 下载](https://github.com/xiaolengWangWang/opcua-ai-studio/releases/download/v0.4.0/OPCUAAIStudio-0.4.0-Windows-x64.zip)。

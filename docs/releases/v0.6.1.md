# OPC UA AI Studio v0.6.1

## 界面

- 不常用的操作按类别收进菜单栏（文件 / 连接 / 读取 / 视图 / 帮助），去掉标题行、第二行连接工具和右下角按钮，数据区多出约 130 像素高度。
- 连接栏一行：已保存的连接、地址、端口、连接设置（齿轮）、搜索服务器、连接 / 断开和状态；粘贴完整 `opc.tcp://` 地址自动拆分为地址和端口。
- “连接设置”对话框集中安全策略、账号、证书、发现端点、断线自动重连和新增的“连接后自动全量读取”。
- 结果区工具栏合并为一行，导出 CSV、导出属性表和复制结果收在“导出”下拉中；读取状态与统计合并为一行，为零的少见计数不再显示。

## 数据查看与写入

- 新增“卡片”视图：每个点一张卡片，大字显示值并按质量着色。
- 新增“趋势”视图：每个数值点位一张小图，显示最近 120 次读取的值和最小、最大值，配合“自动刷新”使用。
- 直接写入：在任一视图选中可写点位，点击结果栏“写入”，在弹出窗口中查看当前值、输入或选择新值、勾选“允许写入”后写入并读回。
- 全量读取、浏览和搜索节点的父节点可只填命名空间，如 `ns=2`，读取 Objects 下该命名空间的全部节点，不浏览命名空间 0 的 Server 对象。

## 搜索服务器

- 修复搜索大量主机时电脑卡死：默认只搜本机所在网段（按网卡实际掩码），跳过 VPN、代理隧道、虚拟机等虚拟网卡和 /31、/32 路由，连接尝试限速，开始前显示地址总数和最长耗时。
- “搜索范围”可选本机网段、其他网卡、仅本机或“指定 IP 或网段”，可只搜索某台主机。

## 多开

- 菜单“文件 › 新建窗口”可同时打开多个窗口连接不同服务器，窗口标题显示所连服务器。
- 多个窗口共用连接配置和通讯记录，同时写入记录互不冲突；程序内更新时，其他窗口仍在使用的旧版本文件不再导致更新失败。
